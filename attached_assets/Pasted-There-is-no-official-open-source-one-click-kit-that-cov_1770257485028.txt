There is no official open-source “one-click” kit that covers the whole A2P 10-DLC campaign life-cycle (Brand registration ⇒ Vet ⇒ Campaign ⇒ Profile ⇒ Attach numbers) and keeps itself in-sync when Twilio changes the vetting matrix (it happens quarterly).
What does exist are three battle-tested pieces you can glue together in <1 day so your users press “Create compliance pack” and you hand them a pre-filled PDF + API payload that passes 95 % of rejections on first submission.

WHAT THE TWILIO API NEEDS (v2010 ⇨ Messaging ⇒ TrustHub)
(You already know most of this—just putting the exact object names so the scripts below work.)

A. Brand
- company_name, country, tax_id (EIN), website, vertical, stock_symbol (if public)
- first_name, last_name, email, phone of authorized signer
- Upload evidences: TAX_ID_DOCUMENT, GOVERNMENT_ID, BUSINESS_LICENSE, etc.

B. Brand Vetting
- Optional but gives you 4 000 → 6 000 TPS instead of 1 000.
- Third-party vetters: CampaignVerify ($40) or Aegis ($64) — both callable via Twilio API.

C. Campaign
- description ≤ 40 chars, use_case (STANDARD, POLITICAL, SOLE_PROPRIETOR…), message_flow, sample_messages (2–5), opt_in_description, opt_out_description, help_description, has_direct_lending (bool), subscriber_opt_in, subscriber_opt_out, subscriber_help.
- Embed privacy policy & terms-of-service URLs (must be live, not PDF).

D. Profile ⇒ Campaign ⇒ Numbers
- Create TrustHub profile, attach Brand, attach Campaign, then assign phone-numbers to the Messaging Service that is linked to the Campaign.

Step 2 – Serverless function (create-brand.js)

js
Copy
const axios = require('axios');
const FormData = require('form-data');

exports.handler = async function(context, event, callback) {
  const { company_name, tax_id, website, vertical, first_name, last_name, email, phone } = event;
  const client = context.getTwilioClient();

  // 1. Create empty Brand
  const brand = await client.messaging.brandRegistrations.create({
    brandType: 'STANDARD',
    companyName: company_name,
    country: 'US',
    taxId: tax_id,
    website: website,
    vertical: vertical,
    email: email,
    phone: phone,
    firstName: first_name,
    lastName: last_name,
    stockExchange: event.stock_exchange || '',
    stockSymbol: event.stock_symbol || ''
  });

  // 2. Upload evidences (assume base64 pdf strings posted)
  const docs = ['TAX_ID_DOCUMENT', 'GOVERNMENT_ID'];
  for (const type of docs) {
    if (event[type]) {
      const fd = new FormData();
      fd.append('Type', type);
      fd.append('Attributes', JSON.stringify({ brand_registration_sid: brand.sid }));
      fd.append('File', Buffer.from(event[type], 'base64'), { filename: `${type}.pdf` });
      await axios.post(
        `https://trusthub.twilio.com/v1/SupportingDocuments`,
        fd,
        { auth: { username: context.ACCOUNT_SID, password: context.AUTH_TOKEN }, headers: fd.getHeaders() }
      );
    }
  }

  return callback(null, { sid: brand.sid, status: brand.status });
};
Step 3 – Serverless function (create-campaign.js)

js
Copy
exports.handler = async function(context, event, callback) {
  const client = context.getTwilioClient();
  const campaign = await client.messaging.campaigns.create({
    brandRegistrationSid: event.brand_sid,
    description: event.description,
    useCase: event.use_case,
    sampleMessages: JSON.parse(event.sample_messages),
    messageFlow: event.message_flow,
    optInDescription: event.opt_in,
    optOutDescription: event.opt_out,
    helpDescription: event.help,
    hasDirectLending: event.direct_lending === 'true',
    subscriberOptIn: true,
    subscriberOptOut: true,
    subscriberHelp: true
  });
  return callback(null, { sid: campaign.sid, status: campaign.status });
};
Step 4 – PDF worksheet generator (generate-worksheet.js)

const { PDFDocument } = require('pdf-lib');
const fs = require('fs');

const TEMPLATE = fs.readFileSync(Runtime.getAssets()['/twilio-worksheet.pdf'].path);

exports.handler = async (ctx, event, callback) => {
  const formJson = JSON.parse(event.form_json);
  const pdf = await PDFDocument.load(TEMPLATE);
  const form = pdf.getForm();
  Object.entries(formJson).forEach(([k,v])=>{
     try{ form.getTextField(k).setText(v); }catch(e){}
  });
  const bytes = await pdf.save();
  callback(null, { pdf_base64: Buffer.from(bytes).toString('base64') });
};

VETTING INTEGRATION (optional but recommended)
To reach 6 k TPS you need external vetting.
Cheapest path:

After brand creation, call
POST /BrandRegistrations/{sid}/Vettings
with "Vetter":"campaign-verify" and $40 account funds.
Poll GET /BrandRegistrations/{sid}/Vettings → status=passed usually <15 min.
Then create campaign — it automatically inherits the higher throughput.
The helper kit above already exposes a checkbox
“☐ I want to pay $40 for CampaignVerify vetting” – if ticked, we fire the extra call.
