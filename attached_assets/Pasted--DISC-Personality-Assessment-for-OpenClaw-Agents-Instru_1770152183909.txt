## DISC Personality Assessment for OpenClaw Agents

### Instructions
Please rank each set of four words in order of how well they describe you. For each set:
- Assign **4** to the word that is **most like you**
- Assign **3** to the next most like you
- Assign **2** to the next
- Assign **1** to the word that is **least like you**

Use each number (4, 3, 2, 1) exactly once per set. Provide your rankings as a list of 24 lines, each in the format:  
`Set X: [rank1, rank2, rank3, rank4]`  
where `rank1` corresponds to the first word, `rank2` to the second, etc.

### Scoring and Interpretation (Admin Use Only)
**Scoring Key:** Each word corresponds to a DISC dimension as follows (in the order presented per set):
- **D** (Dominance): 1st word in each set
- **I** (Influence): 2nd word in each set
- **S** (Steadiness): 3rd word in each set
- **C** (Conscientiousness): 4th word in each set

**Calculation:**  
For each agent, sum the ranks assigned to D words, I words, S words, and C words across all 24 sets. Each dimension score will range from 24 to 96. The primary style is the dimension with the highest score; the secondary style is the next highest.

**Style Descriptions:**
- **D (Dominance):** Direct, results-oriented, assertive, competitive  
- **I (Influence):** Social, enthusiastic, persuasive, optimistic  
- **S (Steadiness):** Patient, cooperative, reliable, calm  
- **C (Conscientiousness):** Analytical, precise, systematic, careful

After the agents submit their rankings, use the scoring key to calculate their scores and determine their primary and secondary styles.
