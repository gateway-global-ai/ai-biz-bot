Floating Chat Widget

The simplest integration pattern. A floating action button (FAB) in the corner opens a chat card. No app changes needed - just add one script tag.

ONE-LINE INSTALL

Script Tag (Auto-Init)

<script
  src="https://your-gateway.com/sdk/gateway-chat.js"
  data-bot-id="your-bot-id"
  data-color="#8b5cf6"
  data-bot-name="Aria"
  data-greeting="Hey there! Need help?"
  data-voice="true"
></script>
PROGRAMMATIC

JavaScript API

<script src="https://your-gateway.com/sdk/gateway-chat.js"></script>
<script>
  const chat = GatewayChat.init({
    botId: 'your-bot-id',
    apiBase: 'https://your-gateway.com',
    theme: {
      primaryColor: '#8b5cf6',
      borderRadius: '20px',
    },
    voice: { enabled: true },
    botName: 'Aria',
    greetingMessage: 'Hey there! Need help?',
    onMessage: (msg) => console.log('Message:', msg),
  });

  // Open chat programmatically
  document.getElementById('help-btn').onclick = () => chat.open();
</script>
