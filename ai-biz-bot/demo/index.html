How to run the demos

  1. Chat & Voice (port 3000): cd ai-biz-bot/ai-voice-sdk-v1 → copy .env.example to .env.local and set GEMINI_API_KEY → npm install && npm run dev
  2. Website Builder (port 3001): cd ai-biz-bot/website-builder → npm install && npm run dev

Then click either card above to open that demo in a new tab.
