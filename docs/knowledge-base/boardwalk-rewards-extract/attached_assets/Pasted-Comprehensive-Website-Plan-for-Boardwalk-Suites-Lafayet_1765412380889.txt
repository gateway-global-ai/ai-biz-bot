Comprehensive Website Plan for Boardwalk Suites Lafayette
Overview
A responsive, full-featured hotel management website integrated with Cloudbeds API v1.3, featuring guest/staff portals and reservation management.

Technology Stack
Frontend: Next.js 14 (React) with TypeScript

UI Components: shadcn/ui + Tailwind CSS

Authentication: 123checkme.com integration + custom employee whitelist

Backend: Next.js API routes (Server Actions)

Database: PostgreSQL (for employee whitelist, feedback, promotions)

Real-time: Socket.io for chat agents

Deployment: Vercel

Key Components & Features
1. Public Website Features
Hero Section: Background video + search availability widget

Hotel Information: Dynamic display from getHotelDetails

Room Inventory: Interactive room selector with filtering (floor, interior/exterior, beds)

Group Booking: Auto-complete group search using getGroups

Promotion Page: Form for Amazon employees to apply for 1-week free stay

Reservation Flow: 5-step booking process

2. Staff Portal Features
Employee Whitelist: Admin-managed authentication system

Booking Agent: Create/manage reservations, apply group codes

Front Desk: Check-in/out, guest lookup, room assignment

Checkout Agent: Checkout process with feedback collection

General Manager: Dashboard with arrivals/departures, housekeeping status, chat interface

3. Authentication System
text
Guest Authentication (123checkme.com):
- OTP via SMS/Email
- Magic links
- Digital signatures for agreements

Staff Authentication:
- Email/password + 2FA
- Whitelist validation
- Role-based permissions (booking, front desk, checkout, manager, admin)

5. Database Schema
sql
-- Employee whitelist
CREATE TABLE employees (
  id UUID PRIMARY KEY,
  email VARCHAR(255) UNIQUE,
  cloudbeds_user_id VARCHAR(100),
  role VARCHAR(50),
  is_active BOOLEAN,
  created_at TIMESTAMP
);

-- Guest feedback
CREATE TABLE feedback (
  id UUID PRIMARY KEY,
  reservation_id VARCHAR(100),
  rating INTEGER,
  comments TEXT,
  created_at TIMESTAMP
);

-- Promotion applications
CREATE TABLE promotion_applications (
  id UUID PRIMARY KEY,
  employer VARCHAR(255),
  employee_name VARCHAR(255),
  email VARCHAR(255),
  status VARCHAR(50),
  created_at TIMESTAMP
);
