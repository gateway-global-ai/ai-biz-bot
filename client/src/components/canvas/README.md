# Governed canvas components

OS-level canvas primitives for Concierge / syscall-backed surfaces. **Do not** use as a generative artboard.

- Import UI from `@/components/ui/*`, `@/ui-core/*`, or `@gateway/canvas-sdk` / `@gateway/design-tokens`.
- No presentation `style={{ }}` or ad hoc hex in this tree — see `VISUAL_INTEGRITY_GOVERNANCE_V1.md`.
- CI: `npm run governance:ui`.
