To reliably control “what’s above the fold” across mobile + desktop, treat your hero as a full-viewport section and let everything else flow normally (no absolute positioning for layout). Then tune spacing with responsive padding + gap.

1) Make the hero exactly one screen tall (so section 2 starts below the fold)

Key idea: Hero = min-height: 100vh, but on mobile Safari you should prefer the newer viewport units:
	•	100svh = small viewport height (stable, avoids address-bar jump)
	•	100dvh = dynamic viewport height (tracks bars; can “jump”)

Plain CSS

.hero {
  min-height: 100vh;      /* fallback */
  min-height: 100svh;     /* best for iOS stability */
  display: flex;
  flex-direction: column;
}

.section {
  padding: clamp(24px, 4vw, 64px) 0;
}

Tailwind (common in React apps)

<section className="min-h-[100vh] min-h-[100svh] flex flex-col">
  ...
</section>

<section className="py-10 md:py-16">
  ...
</section>

That guarantees your 2nd section begins after the hero, i.e. below the fold.

⸻

2) Get “proper” hero spacing (consistent vertical rhythm)

Use a wrapper with responsive px padding and a vertical gap. Avoid manual <br/>/random margins on individual elements.

React structure that behaves well

export default function Landing() {
  return (
    <main>
      <section className="min-h-[100svh] flex flex-col">
        {/* Top bar */}
        <header className="px-5 md:px-10 pt-6 md:pt-10">
          {/* nav */}
        </header>

        {/* Hero content */}
        <div className="flex-1 px-5 md:px-10 flex items-center">
          <div className="w-full max-w-3xl mx-auto flex flex-col gap-6 md:gap-8">
            <HeroIcon />
            <h1 className="text-4xl md:text-6xl font-bold leading-tight">
              Free Custom Websites
            </h1>
            <p className="text-xl md:text-3xl font-semibold opacity-90">
              AI Voice and Chat Enabled
            </p>
            <SearchBox />
            <p className="text-sm opacity-60 text-center">
              Powered by Google Places
            </p>
          </div>
        </div>

        {/* Optional: a little breathing room at bottom */}
        <div className="pb-10 md:pb-16" />
      </section>

      <section className="px-5 md:px-10 py-16">
        <h2 className="text-4xl font-bold">Request Enterprise Access</h2>
        ...
      </section>
    </main>
  );
}

Why this works:
	•	flex flex-col + flex-1 makes the hero content naturally center in the viewport
	•	gap-* controls spacing between hero elements consistently
	•	responsive px + pt/pb prevents cramped mobile and overly tight desktop

3) If you want the hero to hint at scrolling but still keep section 2 below fold

Add a subtle “scroll indicator” inside hero (not by showing section 2).

<div className="pb-8 flex justify-center opacity-60">
  <ChevronDown />
</div>


⸻

4) Common gotchas that break “below the fold”
	•	Absolute positioning major blocks (they overlap instead of pushing content down)
	•	Using h-screen only (can be weird on iOS). Prefer min-h-[100svh].
	•	Huge margin-top on section 2 to “force” it down (will vary by device)
